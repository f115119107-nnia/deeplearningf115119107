小七本機示範客服：預留路由修正套用方式

1. 在正在執行網站的 VS Code 終端機按 Ctrl+C 停止舊伺服器。
2. 將此 ZIP 解壓到專案根目錄（例如 711），保留資料夾結構；覆寫 local-demo/agent.mjs 與 scripts/test-local-agent.mjs。
3. 在 VS Code 終端機確認目前位於專案根目錄，執行：
   node scripts/test-local-agent.mjs
   預期結果：27/27 passed。
4. 重新啟動本機示範網站，並在瀏覽器按 Ctrl+F5 強制重新載入。
5. 輸入「請預留一個海苔飯糰」。應出現待確認摘要及「確認示範預留」按鈕；此時尚未寫入 SQLite。
6. 檢查品項與示範金額後，親自按「確認示範預留」。確認後才會新增匿名示範資料。
7. 按頁面右上方的「本機購物袋」，在對話框的「此 session 已保存的示範預留」區塊截圖。需要資料表截圖時，以 DB Browser for SQLite 開啟 data/local-demo.sqlite，選 Browse Data > demo_reservations。

詢問價格或預留規則不會自動建立待確認動作。這是課堂虛構示範預留，不是 7-ELEVEN 門市庫存預留、訂單或付款。自動測試使用隔離臨時資料庫，不會修改你的 local-demo.sqlite。
